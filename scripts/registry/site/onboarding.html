Getting started

Install once.
Use everywhere.

{{notice}}

Requires macOS or Linux and a compatible Kujo runtime with native package primitives. Kennel does not require Python. No administrator access is needed. The installer adds ~/.kennel/bin to Bash, Zsh and POSIX shell profiles.

Install Kennel

curl -fsSLO https://kennel.kujolang.ai/install.sh
sh install.sh
. "$HOME/.kennel/env"
kennel --version

Inspect install.sh and install.kujo before running them. The shell entrypoint launches Kujo; Kujo downloads, verifies and installs the release. Use sh install.sh --no-modify-path to configure PATH yourself. Fish users can run fish_add_path ~/.kennel/bin.

Global tools

kennel tool install shipcheck
shipcheck --help
kennel tool list
kennel tool update shipcheck
kennel tool remove shipcheck

Tools run from your current directory. Installation records exact versions and checksums and protects existing commands. Exact versions stay pinned; use kennel tool install shipcheck@1.0.0 to select one.

Project dependencies

kennel init --name my-project
kennel add ability
kennel install

Project dependencies stay inside the project and do not add global commands.

Keep Kennel updated

kennel self update

A failed update preserves your current client and tools. Pin a client with kennel self update --version VERSION.

Publish a tool

Enrolled official projects publish through actual GitHub Releases. Keep kennel.toml and release versions aligned; the registry checks for releases every 15 minutes. Declare commands:

[bin]
my-tool = "main.kujo"

Entries may be .kujo files or executable sh, Bash or Python scripts with supported shebangs. A particular third-party script can require its own interpreter; Kennel itself does not. Historical packages can use [kujo].entry. Libraries use kennel add.
